# Newton-Raphson Square Root in Python 🚀

A lightweight, highly efficient Python implementation of the **Newton-Raphson method** for calculating square roots. This script is optimized to minimize redundant calculations (such as repeated exponentiation) for faster convergence.

---

## ✨ Features

* **High Efficiency:** Caches squared values per iteration to eliminate redundant multiplication bottlenecks.
* **Quadratic Convergence:** Utilizes the Newton-Raphson algorithm, meaning the number of accurate decimal places roughly doubles with every iteration.
* **Configurable Precision:** Easily adjust the tolerance level (`epsilon`) to balance between performance and accuracy.
* **Zero Dependencies:** Pure Python implementation requiring no external third-party libraries.
